# Mohammed Warish — Portfolio

AI Engineer portfolio (Next.js App Router). Live: [st-warish.netlify.app](https://st-warish.netlify.app/).

## Stack

- Next.js (static export) + TypeScript + Tailwind
- Framer Motion (Call Path pipeline scrubber)
- MDX case studies in `content/case-studies`

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output is written to `out/` for Netlify (`netlify.toml`).
